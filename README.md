# Bit-Serial-Matrix-Multiplication-Accelerator
Hardware accelerator for bit-serial matrix multiplication implemented in SystemVerilog, developed as my diploma thesis during my studies in Electrical and Computer Engineering.

## Overview
This project focuses on the design and implementation of a custom hardware accelerator for matrix multiplication using an unconventional multiplication algorithm based on bit-serial computation.

The hardware accelerator was designed and verified in SystemVerilog using Vivado, while simulation and benchmarking were performed using the NC Compiler toolchain in a Red Hat Linux environment.

Performance, power consumption and area utilization results were then compared against conventional matrix multiplication implementations, also compiled through NC.

The project was implemented with emphasis on:
- Hardware architecture design
- Automated verification
- Performance benchmarking
- Power consumption analysis
- Area utilization analysis
